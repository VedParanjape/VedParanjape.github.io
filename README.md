# Ved Samir Paranjape — Portfolio

A responsive, multi-page portfolio built with vanilla HTML, CSS, and JavaScript.

## Pages

- Home: portrait, personal introduction, and engineering focus
- Work: project filters and detailed project dialogs
- About: biography, education, skills, and engineering approach
- Contact: email contact links

## Run locally

Open `index.html` in a modern browser, or serve this directory with a static web server. No build step or dependencies are required.

## GitHub Pages

Publish from the root directory of the `main` branch. All asset links are relative, so the site supports either a user site or a project site.

## Customize

Edit the HTML pages for content, `script.js` for project details and interactions, and the CSS files for styling. Images and the VP monogram are in `assets/`.

Project illustrations are conceptual diagrams rather than measured results. The motion control respects reduced-motion preferences.
